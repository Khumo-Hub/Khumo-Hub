###  [AI PR Reviewer Application](https://github.com/Khumo-Hub/AI-PR-Reviewer-application)

An AI-assisted software engineering application that automates parts of the pull-request review process.

**What it does:**

- Receives GitHub pull-request events through webhooks
- Retrieves PR metadata and code changes
- Uses AI to analyse code and identify potential risks
- Produces structured review recommendations
- Integrates with Microsoft Graph
- Creates Outlook review drafts for human approval
- Uses API authentication and webhook signature validation
- Includes automated testing and GitHub Actions CI
- Can be deployed as a FastAPI service

###  [FDI Lens](https://github.com/Khumo-Hub/fdi-lens)

A full-stack **Foreign Direct Investment intelligence platform** designed to explore and analyse global investment activity.

**What it does:**

- Presents executive investment KPIs
- Analyses investment destinations and sectors
- Tracks capital investment, projects and employment trends
- Provides an interactive global investment map
- Includes a searchable and filterable investment-project browser
- Supports server-side filtering, sorting and pagination
- Exposes analytics through a REST API
- Uses automated CI checks for frontend and backend validation

The current application uses **synthetic demonstration data** while providing an architecture that can later support validated public or licensed datasets.

**Technology:**

`React` · `JavaScript` · `Python` · `FastAPI` · `SQLAlchemy` · `SQLite` · `Axios` · `Recharts` · `Leaflet` · `GitHub Actions`
